# Миграции Supabase

В этой папке хранятся миграции схемы и серверных правил «Школьного помощника».

Для первого запуска без Supabase CLI откройте в панели Supabase **SQL Editor**, создайте новый запрос, вставьте содержимое файла `migrations/20260805102000_family_foundation.sql` и выполните его целиком.

Миграция создаёт только основу семейного профиля: одну семью на родительский аккаунт, профиль одного ребёнка и RLS-политики, не позволяющие читать записи другой семьи. Она не создаёт детскую сессию, постоянный PIN или демонстрационные данные.

Остальные файлы из `migrations/` выполняются по возрастанию времени в имени. Если предыдущие миграции уже применены, для полного сценария «Домашки» достаточно выполнить новый файл `20260805150000_homework_review_and_stars.sql` целиком. Он добавляет историю статусов, безопасную проверку родителем и защиту от повторного начисления звезды; секретные ключи для этого не нужны.

Для сценария «Книги» следующим выполняется файл `20260805153000_books_and_reading_diary.sql`. Он создаёт назначенные книги, защищённый детский дневник и подтверждение прочтения с тремя звёздами.

Для сценария «Кружки» затем выполняется `20260805160000_clubs_and_exceptions.sql`. Он добавляет регулярные занятия, настройки напоминания и безопасные отмены или переносы на конкретную дату.

Для облачного экрана «Сегодня» и рюкзака следующим выполняется `20260805170000_today_backpack_and_stars.sql`. Он создаёт чек-лист ближайшего фактического учебного дня, объединяет одинаковые вещи, разрешает ребёнку отмечать только свой список и начисляет одну звезду только после подтверждения родителем.

Если основная миграция рюкзака была применена до исправления неоднозначных выходных имён PostgreSQL, затем выполните `20260805171000_fix_backpack_output_references.sql`.

Для реальных push-уведомлений после всех миграций офлайн-очереди выполните `20260806220000_push_notifications.sql`. Она не содержит секретов и сама ничего не отправляет: создаёт защищённые подписки, настройки, очередь, дедупликацию и триггеры событий. Развёртывание отправщика, VAPID-ключи и ежеминутный планировщик описаны в корневом `PUSH_SETUP.md`.
