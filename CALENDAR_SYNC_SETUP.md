# Синхронизация учебного календаря

Функция создаёт учебный год и предлагает родителю официальные рекомендованные даты каникул. Она никогда не меняет детское расписание до явного подтверждения родителем и не перезаписывает ручные неучебные дни.

## Источники

- текст документа: публичный архив и документ `КонсультантПлюс`;
- проверочная ссылка: раздел «Документы недели» ФГБУ «Аналитический центр» Минпросвещения России.

Автоматический импорт поддерживает только общие рекомендации для четвертной системы. Дополнительные каникулы первого класса не импортируются, пока в продукте нет подтверждённого класса ребёнка. Календарь конкретной школы может отличаться, поэтому родитель всегда видит источник и подтверждает даты вручную.

## 1. Миграция

В Supabase SQL Editor целиком выполните:

`supabase/migrations/20260811143000_school_calendar_proposals.sql`

Миграция добавит источник 2026/2027, создаст безопасные предложения для существующих семей и поставит уведомления родителям в уже существующую очередь Web Push.

## 2. Edge Function

Разверните папку `supabase/functions/sync-school-calendar` как функцию `sync-school-calendar`. Для неё должен быть выключен встроенный `Verify JWT`: запрос защищён заголовком `x-cron-secret` и существующим секретом `CRON_SECRET`.

Новые секреты не нужны. Среда Supabase предоставляет `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`, а `CRON_SECRET` уже используется отправщиком push.

## 3. Ежегодный запуск

В SQL Editor целиком выполните:

`supabase/setup/schedule_school_calendar_sync.sql.example`

Задание запускается ежедневно в 21:15 по Самаре с 30 мая по 30 сентября. Первый запуск создаёт новый учебный год, а последующие без дублей проверяют публикацию рекомендаций. Временная недоступность источника не считается успешным импортом: функция вернёт `source_temporarily_unavailable` и повторит проверку на следующий день.

Используются существующие Vault-секреты:

- `school_assistant_project_url`;
- `school_assistant_push_cron_secret`.

## 4. Проверка

1. В родительском интерфейсе выберите новый учебный год.
2. Убедитесь, что виден номер документа, две ссылки и перечень дат.
3. Нажмите «Подтвердить и добавить».
4. Проверьте, что ручные даты сохранились, а рекомендации появились в списке.
5. На устройстве ребёнка убедитесь, что каникулы влияют на расписание только после подтверждения.
6. Для диагностики смотрите Edge Functions → `sync-school-calendar` → Logs и таблицы `school_calendar_sources`, `family_calendar_proposals`, `notification_outbox`.

Для одноразового вызова без публикации секретов выполните
`supabase/setup/test_school_calendar_sync.sql.example`, затем проверьте, что в
Edge Functions → `sync-school-calendar` → Invocations появился ответ `200`.

Не публикуйте `CRON_SECRET`, service-role ключ или содержимое push-подписок в репозитории и скриншотах.
