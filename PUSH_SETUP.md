# Настройка Web Push

Код приложения не содержит закрытых ключей. До публикации интерфейса уведомлений нужно один раз настроить Supabase и Vercel в указанном порядке.

## 1. Схема данных

В Supabase SQL Editor выполните целиком:

`supabase/migrations/20260806220000_push_notifications.sql`

Миграция создаёт настройки, отдельные подписки устройств, очередь с уникальным ключом события, безопасные RPC и триггеры домашки, рюкзака и читательского дневника.

## 2. Ключи VAPID и ключ планировщика

Локально выполните `pnpm push:keys`. Команда создаёт новый набор. Закрытые значения не отправляйте в чат и не добавляйте в Git.

- `VAPID_PUBLIC_KEY` используется в Supabase и как `VITE_VAPID_PUBLIC_KEY` в Vercel.
- `VAPID_PRIVATE_KEY` хранится только в Supabase Edge Function Secrets.
- `CRON_SECRET` хранится в Supabase Edge Function Secrets и Supabase Vault.
- `VAPID_SUBJECT` задайте как `https://school-assistant-one.vercel.app/`.

## 3. Edge Function

Разверните функцию `dispatch-push` из `supabase/functions/dispatch-push/index.ts`. В проекте уже есть `supabase/config.toml` с `verify_jwt = false`: сама функция принимает только POST с точным `x-cron-secret`.

В Supabase Edge Function Secrets добавьте:

- `VAPID_PUBLIC_KEY`;
- `VAPID_PRIVATE_KEY`;
- `VAPID_SUBJECT`;
- `CRON_SECRET`.

`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` предоставляет среда Supabase; их не нужно копировать в клиент или Vercel.

## 4. Серверный планировщик

Откройте `supabase/setup/schedule_push_dispatch.sql.example`, замените только `<PROJECT_URL>` и `<CRON_SECRET>`, вставьте результат в новый запрос SQL Editor и выполните. Заполненный SQL не сохраняйте в репозиторий.

Планировщик вызывает Edge Function каждую минуту. Функция рассчитывает время в `Europe/Samara`, создаёт только события в ближайшем окне, пропускает отменённые и перенесённые кружки, блокирует параллельные попытки и повторяет временные ошибки до пяти раз.

## 5. Vercel и проверка

В Vercel добавьте `VITE_VAPID_PUBLIC_KEY` для Production и Preview, затем выполните новый deployment.

Проверка выполняется только после явного действия пользователя:

1. На устройстве родителя откройте раздел уведомлений и нажмите «Включить уведомления».
2. На iPhone ребёнка сначала добавьте PWA на экран Домой, откройте её с иконки, затем в профиле нажмите «Включить уведомления».
3. На каждом устройстве нажмите «Проверить уведомление» и подождите до одной минуты.
4. Отправьте домашку, рюкзак и книгу с устройства ребёнка; родителю должно прийти по одному событию каждого типа.
5. Измените время тестового напоминания на ближайшие несколько минут и проверьте доставку по Самаре.
6. Отзовите подписку в родительском списке устройств и убедитесь, что новые уведомления на неё не приходят.

Для диагностики используйте Edge Functions → `dispatch-push` → Logs и таблицу `notification_outbox`. Не отправляйте содержимое подписок или секретов в скриншотах.
